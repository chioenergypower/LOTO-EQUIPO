# LOTO EQUIPO

Webs de trabajo del equipo (limpieza, mantenimiento). Cada persona entra con su enlace personal.

- `limpieza/` — página del equipo de limpieza
- `mantenimiento/` — página del equipo de mantenimiento (partes de avería)
- `config.js`, `api.js` — conexión con la base de datos (solo responde a enlaces personales válidos)
- `sql/` — estructura y funciones de la base de datos (sin datos)

Aquí no se guardan códigos de acceso, datos de clientes ni claves.
